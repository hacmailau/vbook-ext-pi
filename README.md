# vbook-ext-pi

vBook extensions.

- **9Router Translate** (`9router-translate`): translate engine using a 9Router OpenAI-compatible endpoint. Default model `cbai/deepseek-v4.1-flash`; enter the API key in the extension settings.

Add this repository in vBook with:

`https://raw.githubusercontent.com/hacmailau/vbook-ext-pi/main/plugin.json`
